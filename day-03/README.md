## What I Learned

This day focused on understanding how Python functions work and how they can be made more flexible and reusable.

I learned how to use default arguments, accept a variable number of arguments using *args, return values from functions, and return multiple values from a single function.

I also practiced using Python's built-in functions such as min(), max(), sum(), and sorted() to process data.

Another important concept was variable scope. I learned how local and global variables behave and how the global keyword can be used when a function needs to modify a global variable.

Finally, I learned how Python modules work by creating and importing a custom temperature_utils module and using standard library modules such as random and datetime.

## Challenges Faced

The most challenging concepts were understanding *args, variable scope, and the global keyword.

Creating and importing a custom module was also new and required careful attention to the file structure and import statement.

I worked through these challenges by breaking each problem into smaller parts, testing the functions with different inputs, and checking the output step by step.
